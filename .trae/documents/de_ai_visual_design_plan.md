# 去 AI 味视觉设计改造计划

> 目标：将当前 AI 生成风格的通用视觉（玻璃拟态、对称布局、安全色、系统字体）改造为具有独特个性、手绘质感、日系恋爱游戏气质的视觉语言。

---

## 一、问题诊断：当前 UI 的 AI 味特征

### 1.1 色彩系统
| 问题 | 表现 |
|-----|-----|
| 主色 `#7B8CDE` | 典型 AI "安全色"—— 一个不冷不暖、不蓝不紫的平庸紫色，没有任何情绪倾向 |
| 背景 `#0A0A0C` | 纯粹的接近黑色，所有同类 App 都在用 |
| 辅助色 | iOS 系统色直接搬运（`#FF453A`, `#FF9F0A`, `#64D2FF`），无品牌个性 |
| 文本层级 | `textPrimary / textSecondary / textTertiary` 三级灰色梯度，所有卡片信息严重依赖此单调结构 |

### 1.2 组件语言
| 问题 | 表现 |
|-----|-----|
| 玻璃拟态滥用 | `GlassContainer` 成为所有内容的默认容器，5+ 处页面每个区块都是玻璃+背模糊 |
| 过度背模糊 | `BackdropFilter` + `blurSigma=20` 在任何地方出现，性能负担且无视觉区分度 |
| 圆角强迫症 | 全项目圆角都是 `16px` 或 `20px`，每个元素都是同样的胶囊/圆角矩形 |
| 0.5px 描边 | `border: Border.all(color: AppColors.border, width: 0.5)` —— 这行代码出现至少 **10+ 次** |
| `withAlpha()` 透明叠色 | `accent.withAlpha(30/40/60/120/180)` 作为所有次级色生成方式 |

### 1.3 排版 & 布局
| 问题 | 表现 |
|-----|-----|
| 系统字体 | `.SF Pro Display`，没有字符感的字体 |
| 单调字号梯度 | `11, 12, 13, 14, 15, 16, 17, 20, 24, 28` —— 完全的线性递增 |
| 完美居中 | 每个 `GlassContainer` 内部都是完美垂直+水平居中，每个 Row 都是 `MainAxisAlignment.center` |
| 完美对称 | 左右 padding 永远 `20, 20`，上下永远 `16, 16` |
| 图标泛滥 | `CupertinoIcons` 出现在任何可能的位置，标签用图标、数据用图标、分隔用图标 |

### 1.4 交互
| 问题 | 表现 |
|-----|-----|
| 通用对话框 | `CupertinoAlertDialog` 用于所有弹窗场景 |
| 无状态区分 | 激活/禁用的视觉区分仅是透明度变化 |
| 无过渡动画 | 页面切换仅是淡入淡出 `250ms` |

## 二、设计方向：日系校园恋爱游戏风

### 2.1 视觉关键词
- **温暖**：不冷不硬的色调（暖米白、樱花粉、淡金）
- **手绘**：轻微不规则的圆角、细微的线描质感
- **故事感**：标题字体有衬线感、正文用易读的黑体
- **克制**：不使用玻璃拟态、不滥用模糊
- **层次感**：不同区块有不同的表面质感，而不是统一玻璃

### 2.2 灵感参考
| 方向 | 说明 |
|-----|-----|
| 文字游戏 UI | `STEAM` 日系视觉小说界面风格（带书名标题、角色对话框风格） |
| 日系排版 | 大标题用宋体/黑体混合、正文清晰易读、数字有等宽感 |
| 卡片设计 | 轻描边 + 软阴影，取代玻璃拟态 |

## 三、具体改造方案

### 3.1 色彩系统（全部重写 `main.dart` 中的 `AppColors`）

**新增核心色板：**
```
# 主色（恋爱感的樱花红 —— 不是纯粉，带一点橙调）
accent:      #E96E7D （取代 #7B8CDE）

# 次色（温暖的金棕色，用于强调按钮/数据）
secondary:   #D4A373

# 背景（深暖灰，不是纯黑 —— 带 2% 的红棕调）
background:  #1C1A1E
surface:     #2A262C   (卡片底色)
surfaceAlt:  #252127   (次级卡片底色)

# 文本（不再是三级灰梯度，而是暖色文本）
textPrimary:  #F5EDE3   (暖米白)
textSecondary:#C8B8A3   (暖金灰)
textTertiary: #8A7C6B   (暖棕灰)

# 功能色（重新调色，不是 iOS 系统色）
error:       #D4576B   (暖红，不是 #FF453A)
warning:     #E8B15A   (暖金，不是 #FF9F0A)
success:     #7FB38A   (柔和绿)
info:        #8BA8C9   (柔和蓝)

# 描边（有实际颜色，不是 withAlpha 的透明叠加）
border:      #3D3840   (带暖调的深色描边 1px)
borderSoft:  #2E2A30   (更弱的区分线)
```

### 3.2 字体系统
```
标题字体: 加粗黑体（fontWeight.w800）
正文字体: 常规黑体
数字/等宽: 等宽数字字体用于数值显示（好感度、日期等）
字号梯度: 11 / 13 / 15 / 17 / 22 / 28（跳过 12/14/16/18/20/24，打破线性）
```

### 3.3 组件库改造（核心改造文件 `lib/main.dart`）

**废弃 `GlassContainer` / `GlassNavigationBar` / `glass()` extension**

新建替代组件：
```dart
// 1. SurfaceCard —— 基础卡片
//    特性：1px 暖色描边 + 温暖底色 + 非常轻微的底部阴影
//    圆角：14px（不再是 16）
//    不使用 BackdropFilter

// 2. SurfaceCard.premium —— 高级卡片（带轻微渐变底色）
//    特性：左上 → 右下的浅金色渐变底色

// 3. SoftChip —— 轻标签
//    圆角: 8px，圆角矩形（非胶囊）

// 4. SolidButton / GhostButton / SoftButton —— 三种按钮层级
//    SolidButton: 实心主色 + 阴影
//    GhostButton: 描边按钮
//    SoftButton:  浅色底色按钮

// 5. LabeledText —— 带标签的文本行
//    用于：角色信息、设置项等（取代当前的 Row+Row 重复写法）

// 6. StatusBadge —— 状态徽章
//    用于：已读/未读、已加载等状态（取代当前的小圆点 Container 自定义写法）
```

### 3.4 聊天界面改造 (`chat_screen.dart`)

**当前问题：** 气泡是玻璃+背模糊，玩家和 AI 的气泡颜色区分弱

**改造方向（日系对话框风格）：**

```
玩家消息气泡:
  → 纯色背景 `#E96E7D`（带轻微渐变 95% → 80%）
  → 圆角：左上 20px, 右上 20px, 左下 4px, 右下 20px
  → 文字：纯白 `#FFFFFF`
  → 无描边
  → 轻微下阴影 (0,2) blur:6, opacity: 0.3

角色消息气泡:
  → 暖色卡片背景 `#2A262C`
  → 圆角：左上 20px, 右上 20px, 左下 20px, 右下 4px
  → 左侧 3px 宽的角色主色竖条（每个角色不同色）
  → 1px 暖色描边 `#3D3840`
  → 字体: 暖米白文字

头像:
  → 圆形 40px（不再是圆角矩形）
  → 未读红点改为右上带小闪光的红色圆点
```

### 3.5 角色资料页改造 (`character_profile_screen.dart`)

**改造方向（角色卡片风格，不再是玻璃列表）：**

```
顶部 Header 区:
  → 不再是纯色渐变背景，改为角色主色的柔和纯色背景
  → 头像：120px 圆形（当前 96px），带 4px 白色内环 + 2px 暖色描边
  → 角色名：28px 粗体，居中
  → 原名：如果有备注名，原名 13px 灰，显示在大名下
  → 标题"头像可点击替换"改为小字悬浮提示样式

好感度区:
  → 横向大卡片，左侧显示"♥"字符（不是图标），右侧显示大号数字
  → 数字：使用等宽字体，字号 32，主色
  → 移除 "SF Mono" 字样，改用 Flutter built-in monospace
  → 下方添加一条横向刻度条（5 段，从陌生→恋人），取代 AffectionBar

基础信息区:
  → 每行使用 LabeledText 组件（左标签灰色、右内容主色）
  → 标签使用「姓名」「年龄」等文字，不是图标

角色简介区:
  → 标题下方加一条 40px 长的暖色分隔线
  → 标签改为椭圆形浅色背景（不是玻璃描边）

底部按钮:
  → SolidButton 风格大按钮
```

### 3.6 剧本页改造 (`scripts_screen.dart`)

**改造方向（书籍/剧本卡片风格）：**

```
剧本卡:
  → 不再是玻璃卡片，改为白底（深色模式下是 `#2A262C`）+ 1px 描边
  → 左侧是一个"书籍封面"色块（渐变，带剧本标题的第一个字）
  → 右上角：加载状态徽章（如果已加载）
  → 底部按钮：SolidButton（加载） / 软灰色（正在使用）

主角设定区:
  → 输入框不再是玻璃风格
  → 改为：白底卡片，输入框有底部 1px 描边（当聚焦时变主色）
```

### 3.7 联系人列表改造 (`contacts_screen.dart`)

```
每行:
  → 圆形头像（不再是 12px 圆角矩形），大小 48px
  → 右侧三行信息（角色名 / 最新消息 / 时间）
  → 分隔线：底部 0.5px（从头像右侧开始）
  → 未读角标：红色圆形 + 数字，位置右上
```

### 3.8 模拟/存档页改造 (`root_screen.dart` 的 SimSlotsScreen)

```
存档卡片:
  → 卡片式布局（不是玻璃列表）
  → 左侧：剧本封面图块（不是渐变小图标）
  → 标题：剧本名 + 天数
  → 小字：保存时间
  → 底部操作区：软按钮组（不是 CupertinoButton）
```

### 3.9 底部 Tab 栏改造

```
→ 不再是纯色背景
→ 使用 `#252127` 背景 + 顶部 1px 暖色描边
→ 选中态：主色文字 + 下方 3px 主色指示条
→ 图标：保持 Cupertino 图标但换颜色和大小（20px，不是 22px）
```

## 六、设计原则（执行时遵循）

1. **不使用 `BackdropFilter`/`ImageFilter.blur`** —— 玻璃拟态是最大的 AI 味来源
2. **不使用 `Color.withAlpha()` / `withOpacity()` 做次级色** —— 使用定死的实际色值
3. **不使用 iOS 系统色值**（`CupertinoColors` 的内置颜色）—— 全部用项目自己的颜色
4. **圆角不超过 20px** —— 打破"所有东西都是大圆角"的 AI 习惯
5. **不全部居中** —— 列表左对齐，标题左对齐，仅头部标题或特殊提示居中
6. **减少图标使用** —— 能用文字标签就不用图标，尤其减少 `CupertinoIcons` 的使用
7. **阴影克制** —— 仅在按钮和需要浮起感的卡片用轻阴影
8. **描边有颜色** —— 不使用 `0x12FFFFFF` 这类几乎看不见的透明描边
